# Mintlify (mintlify)
Mintlify is an AI-native intelligent documentation platform designed for the next generation of technical documentation, combining beautiful out-of-the-box design with advanced collaboration and AI capabilities. The platform integrates AI throughout the documentation lifecycle with a context-aware agent for self-updating knowledge management, an embeddable AI assistant, native llms.txt and MCP support, and APIs for deployment, agent jobs, assistant chat, search, and analytics.
